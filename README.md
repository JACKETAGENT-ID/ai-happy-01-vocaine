# Rainbow Puddle Voyage

A captain mouse in a red scarf sails a paper boat across a puddle that mirrors a rainbow, while a frog cheers from a leaf. Soft watercolour, warm light, one small brave adventure.

Entry for make.fun's "Make the AI judge happy" bounty (ai-happy-01). `main.ts` copies the bundled image to the output path the competition asks for, byte for byte, deterministically.
